## 教訓
### L1:重建 image 就是升級依賴——未釘版的 requirements 每次 build 都在賭
- 現象:為加開機蓋章重建 v19/v20 image,當天 Anthropic LLM 串流開始間歇 APIConnectionError(未定罪但成頭號嫌疑)
- 根因:requirements.txt 只釘 livekit 系,anthropic/httpx 浮動;docker build=重新 pip resolve,「只加兩行 code」的部署實際上是「順便升了不知道幾個套件」
- 下次:改 agent 任何檔要重建 image 前,先 pip freeze 比對關鍵依賴或全面釘版;出現新錯誤第一問「這次 build 拉到了什麼新版本」
- 對應 feedback:glue_layer_errors_lie(版本歪斜)、capacity_constants_expire(隱性環境快照過期)
