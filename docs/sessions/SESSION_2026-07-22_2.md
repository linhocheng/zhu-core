## 教訓
### L1：兩顆語意相近的開關必然被混用——命名與 UI 要把差異寫在臉上
- 現象：Adam 點了「自動通關」（contentGate）以為會開「校對權限」（通關碼），畫面顯示「尚未開通校對權限」更加深誤會
- 根因：兩個功能都叫「通/關」家族詞，UI 沒有在任一處說明彼此關係
- 下次：設計成對開關時自問「用戶會不會以為 A 就是 B」；答會→改名或在 UI 互相指路（已在租戶頁文案補）
- 對應 feedback：interface-blood-vessel-check（顯示層＝血管的一部分）
### L2：push 後必看 CI——紅燈沒人看等於沒有 CI
- 現象：早上 v2.8.1 push 後 audit gate 就紅了（sharp CVE），半天後接測試時才發現
- 根因：CI 裝了但「看結果」沒進動線；紅燈無通知＝靠自律＝會漏（信念 7 反面教材）
- 下次：每次 push 後 `gh run list --limit 1` 看一眼進收線動線；連紅兩次的 repo 先查 CI 再開新工
- 對應 feedback：silent-failure-absent-log（缺席的信號要主動去看）
