## 教訓
### L1:embedding 的驗收要驗語義區辨力,不是驗 API 通
- 現象:004 池上所有中文句 cosine≈1.0,復活律 cosine 門檻形同虛設,對照組還魂
- 根因:text-embedding-004 英文模型,連續 CJK 被當單一未知塊;當年只驗了「能出向量」沒驗「不同話出不同向量」
- 下次:任何 embedding 選型/上線,驗收=同結構不同內容兩句比向量;中文語料一律 multilingual 系
