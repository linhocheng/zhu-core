## 教訓
### L1：上限型防護的計量單位要對齊防護對象（費用版）
- 現象：成本閘 500 searches 被 Gemini 免費搜尋（一題 8-19 次、$0）觸發，324 筆監測誤殺在 263
- 根因：防的是錢、數的是動作；免費動作不是成本
- 下次：設任何 quota/上限先問「我在防什麼」，計量單位直接用那個東西（防錢數錢）
- 對應 feedback：skill_filter_unit_matches_error_shape（已追加費用版）

### L2：Cloud Run 反向代理後 req.url 是容器內部位址
- 現象：登入成功 redirect 到 https://0.0.0.0:8080/
- 根因：Next.js route handler 的 req.url 反映容器 HOSTNAME:PORT，不是對外域名
- 下次：Cloud Run 上任何 server-side redirect 用 x-forwarded-host + x-forwarded-proto 組 origin（geo-authority admin/src/lib/origin.ts 可抄）

### L3：監視器要鎖唯一鍵，不是「最新一筆」
- 現象：盯 beselfaviva monitor 的 watcher 抓到我 dry-run 後取消的週單，誤報 canceled
- 根因：查詢條件「該租戶最新 monitor job」在多單並存時指向會漂移
- 下次：watcher/輪詢一律鎖定不變的唯一鍵（jobId/batchId），建立時就把鍵拿在手上
