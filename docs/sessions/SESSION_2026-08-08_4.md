## 教訓

### L1：LLM 驅動的方法論，「彈性」要傳遞意圖的機制，不是傳遞更多素材
**現象**：Gina 覆盤法第 1 步開場寫死「問顏色＋小秘密」。要它彈性，我第一反應是換素材（天氣/季節/地理）並接進 prompt——被 Adam 連糾兩次才到「意圖層」。
**根因**：把「彈性」誤解成「素材多樣性」。但每次問顏色的病不是「素材不夠多」，是「開場被寫成戰術而非意圖」——換一個固定素材只是換焊點。角色要能自主生招，需要的是「這一步要達成什麼意圖＋為什麼這類招有效（＝好招的準則）」，素材是它生招時的下游原料。
**下次**：寫 LLM agent 的可變行為指令時，先問「我在傳戰術/台詞/素材，還是在傳意圖＋其機制？」。方法論 authoring 對應原則：「寫目標不寫台詞」再深一層＝「傳意圖的機制，不焊戰術」；共創時問角色「什麼算好開場」不只「舉一個例子」。
