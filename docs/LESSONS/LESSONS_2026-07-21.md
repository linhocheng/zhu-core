# LESSONS 2026-07-21 · 三站 CSP nonce 化——同模板複製 UDN/geo/ailiveX，每站雷不同逐站真瀏覽器驗，全部署 production 驗綠

### L1：同模板複製到多站，每站都要逐站真瀏覽器測——模板過一站不等於全過
現象：同一份 CSP nonce 模板，geo 一次過、UDN 撞 Next 16 靜態頁死白頁（0/15 nonce）、ailiveX 撞外部 Google Fonts 被 style-src 擋。三站三種不同破法。
根因：模板消滅共通結構，但每站的框架版本／字型載法／靜態頁分布／既有 middleware 各不同——這些差異正是模板沒覆蓋、會咬人的地方。
下次：複製前端加固模板到多站，逐站跑真瀏覽器測（playwright headless），收三信號：script nonce 覆蓋 N/N、0 CSP violation、client 軟導航（window 未重載＝真 hydrate，比 __next_f 可靠）。心裡冒出「一樣的改法應該都會過」就是要逐站真測的訊號。
對應 feedback：[[feedback_flagged_risk_must_be_verified]]＋[[skill_csp_nonce_per_site_headless_verify]]。

### L2：Next 16 三個破壞性雷（升級/加固 Next 平台前必知）
現象：middleware.ts 在 16.2 改名 proxy.ts（16.1 仍認 middleware.ts）；靜態頁 nonce 對不上→strict-dynamic 全擋死白頁；`window.__next_f.length` hydrate 後被清空、不是有效探針。
根因：Next 16 一系列 breaking changes（AGENTS.md 開頭就警告「This is NOT the Next.js you know」）。
下次：動 Next 16 前先核版本＋讀 `node_modules/next/dist/docs/`；nonce 必配 root layout force-dynamic；hydration 驗證用軟導航不用 __next_f。
對應 feedback：[[reference_nextjs16_csp_nonce]]（完整技術細節）。
