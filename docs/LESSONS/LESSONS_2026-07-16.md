# LESSONS 2026-07-16 · GPT 即時語音一晚全迴圈——深研→建線→實測→判負退役，量尺與插座落袋

### L1：外部 S2S 模型的人格保真要當二元閘門先測，不當旋鈕慢調
- 現象：GPT Voice 線功能全通（靈魂/記憶/工具/收尾），但直問「你是誰」即自報 ChatGPT、否認 context 內記憶；身份錨 prompt 無效
- 根因：底模「誠實 AI」身份訓練在權重層，直球質問下必然壓過 instructions——這不是 prompt 寫不好，是層級輸了
- 下次：評估任何外部語音/S2S 模型，第一刀先做人格三連測（直問你是誰×3），不過關就不用往下測延遲和成本；驗收三連＝問身份/幻聽稽核/打斷率
- 對應 feedback：ai_sycophancy_is_baked_in（同構：烤進權重的天性，prompt 是地板）

### L2：對照組實驗意外翻案共用路徑的鍋
- 現象：GPT 線聽想配線與 v18 完全不同，首通首音卻同樣 ~18.6s（v18 基線 18.0s）
- 根因：瓶頸在兩線共用的開場路徑（建線/組 prompt/agent 首回合），不在 STT→LLM→TTS 管線選型
- 下次：懷疑管線慢時，先找「換了引擎但共用底盤」的對照組數據；兩條不同管線同樣慢＝鍋在底盤
- 對應 feedback：solve_root_not_symptom（換引擎修不了車庫門）

### L3：音訊模型的幻聽會偽裝成「第三者在場」
- 現象：Adam 問「是有其它第三者在跟他聊嗎」；transcript 抓到 [user] Evet.（用戶沒說的土耳其語）＋無 user turn 的連發回應
- 根因：VAD 誤觸把噪音/回音送進音訊模型 → 模型從噪音「聽出」語言（音訊版幻覺）→ 認真回應幻聽
- 下次：語音線出現「答非所問/像跟別人聊」，第一刀翻 transcript 找用戶沒說過的 user turn——幻聽輸入有紀錄可稽核，體感不用猜
