# LESSONS 2026-07-13 · S 姐姐「原生認知」規格落地——UDN 補判斷層、ailiveX 磨四刀，兄弟平台首次互相體檢

### L1：加表達規則時，量尺要同步盯「規則被機械化執行」的反彈
現象：SPEAK 加「同意要指名主張」後，角色一律翻成「你說…」句首開場（4/9 輪，原 0/11）——規則被過度執行成新的口頭禪。
根因：模型對規則的執行會坍縮到最顯眼的表面形式（句首位置）；規則本身沒錯，錯的是執行形狀。
下次：每加一條表達規則，同場跑量尺看它的「過度執行形狀」；修正瞄準形狀（句首位置）不撤規則本身。
對應 feedback：filter-unit-matches-error-shape（攔截單位對齊錯誤的真實形狀）。

### L2：同源移植的兄弟平台要帶蟲單互相巡檢
現象：ailiveX 踩過並修掉的三隻蟲（EOS 洩漏/多段落蒸發/靜默跳輪），在移植出去的 UDN worker 裡全數潛伏，其中多段落蟲連正則都一模一樣。
根因：移植發生在修蟲之前；修蟲時只修了眼前的 repo，沒問「這段代碼還活在哪裡」。
下次：修移植代碼的蟲時，末尾固定一問「同源副本在哪」，帶著蟲單巡檢兄弟平台；tts-normalize 的四落點同步清單就是這件事的既有範本，適用範圍比想的大。
對應 feedback：backend-client-must-sync＋四落點同步清單（reference_opencc_s2t_pitfalls）。
