# LESSONS 2026-08-01 · BeSelf 商品庫+品名兜底+後台整體換裝 v1.0.0+Nina(原 Ava)產品知識全裝——完整一天

### L1:跨庫搬運先驗連結活著——re-ingest 過的主檔指著死鏈
- 現象:兩件產品的 knowledgeIds 全 MISSING(源庫後來重新入庫,舊段落被刪,主檔沒更新指標)
- 根因:聚合 doc 的外鍵陣列不隨被指對象的生滅維護——讀側看起來完整,解引用才知道死
- 下次:跨庫搬運三層 fallback 順序:①解引用驗活(exists+content>20)②標題前綴撈活段落(複合索引沒有就全量本地濾)③退回主檔欄位+確定性清洗(圖說垃圾切尾)
- 對應 feedback:memory_can_lie(資料庫版——指標也會說謊)

### L2:量測探針自己要先被驗證——「等文字」不等於「等資料」
- 現象:煙測等到「件商品」字樣就開始等圖,但字樣在 0 件時就 render 了;探針量的是 hydration 中間態,25s PENDING 差點誤診 App 斷圖(圖檔 curl 200+PIL 可解)
- 根因:React 頁的「出現某字」和「資料到位」是兩個時刻;把中間態當終態量,量出來的是幻覺
- 下次:動態頁探針兩段式——先等元素數量到位(document.images.length≥N),再等狀態到位(every complete&&naturalWidth>0);誤診方向要雙查:標的真壞 vs 探針量錯
- 對應 feedback:ambiguous_signal_not_proof(量測工具版)

### L3:改名不是改一筆,是掃引用——正名的「兩份即是零份」
- 現象:慕絲花本體正名後,雪玉如初的使用流程段落還引用舊名,驗收抓到殘留
- 根因:名字散在引用處;改本體不掃引用=庫內兩個名字並存,檢索兩頭都命中一半
- 下次:任何正名操作,收案信號=corpus 全域 grep 舊名為零;修法=受影響 doc 整份確定性替換+刪除重入(embedding 跟著新文本重算)
- 對應 feedback:defend_at_convergence_point+破索式(兩份即是零份)

### L1：中文排序不用 localeCompare——collation 隨環境變＝非確定
- 現象：mergeTeamKeywords 輸出排序測試紅（'防曬' vs '卸妝' 順序與預期反）
- 根因：localeCompare 的中文 collation 依 Node ICU/locale 而變；「確定性純函數」裡藏了一個環境相依
- 下次：純函數裡的排序一律 code-point 比較（`a<b?-1:1`）；localeCompare 只准出現在 UI 顯示層
- 對應 feedback：deterministic_work_belongs_in_code
### L2：部署鏈有資料遷移時，先算「誰會在窗口裡開火」
- 現象：台北 02:00 cron 在「新 worker 已上、帳號 backfill 未跑、新分派器未上」的窗口開火，留一筆 failed 殘影
- 根因：部署順序只想了「代碼相容」（legacy CLIENT_ID fallback 有做），沒想「定時觸發器會在窗口中間進來」；02:00 正好撞遷移分鐘級空隙
- 下次：改調度/遷移前先查「下一次自動觸發是幾點」，要嘛趕在觸發前收完整條鏈，要嘛先把觸發暫停（改 due 條件/暫停 cron）再施工
- 對應 feedback：capacity_constants_expire 的近親——「時間窗」也是現場的一部分

### L1：Edit 前用 Read 工具讀檔，Bash cat 不算數——同型滑倒 7 次
- 現象：整場 Edit-before-Read 被 guard 擋 7 次（globals.css/collections/auth/routes/setup-iam…），每次都是先用 Bash cat/grep 看過檔案就以為可以 Edit
- 根因：工作記憶把「看過內容」和「工具鏈認可的已讀」混為一談；Bash 讀的不進 Edit 的前置檢查
- 下次：要改的檔案一律先 Read 工具（哪怕只 Read 目標行段）；Bash grep 只用來「找位置」不用來「取代讀」
- 對應 feedback：醉酒指數的工具滑倒信號——這場就是靠它累到 8 分
### L2：接外部服務前先做「分裂判決」設計——多源交叉驗，裁判給行為不給標籤
- 現象：靜態 IP 的 ASN 一家說 hosting 一家說不是（2:1）
- 根因：IP 信譽資料庫各家分類法不同，單源是雜訊；真正的裁判是目標平台的行為（Threads 放不放行）
- 下次：買 IP/proxy 類資源驗收＝多源 flag 交叉＋真實負載實測雙軌，標籤打架時以行為為準、標籤記為觀察項
- 對應 feedback：ambiguous_signal_not_proof＋glue_layer_errors_lie
