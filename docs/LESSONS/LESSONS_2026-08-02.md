### L1：build/deploy 指令必帶絕對路徑，cwd 漂移會在錯的 repo root 留殭屍
- 現象：compound command 後 cwd 落在 repo root，`npx next build`＋`npx vercel --prod` 在 root 誤跑→root 多出 .next/ 殘渣＋.vercel link＋.gitignore 被 vercel 自動改
- 根因：Bash 工具 cwd 跨呼叫持續但被 cd 汙染；build/deploy 這類「在哪跑很重要」的指令沒鎖路徑
- 下次：next/vercel/npm test 一律 `cd <絕對路徑> && ...` 開頭；deploy 前先 `pwd` 級確認
- 對應 feedback：工具滑倒家族（醉酒指數信號）
### L2：LLM 長 JSON 單發呼叫要標配「重抽一次＋失敗診斷」
- 現象：analyze 首跑 parse 不合格寫 failed；本機重放同 prompt 一次即通
- 根因：長結構化輸出（1.5k+ tokens JSON）機率性偶壞是常態不是 bug；單發呼叫沒有重試就把機率暴露給使用者
- 下次：分析類單發 bridge call 標配 for 2 次迴圈＋失敗記 stop_reason/tokens/len/head（診斷欄位讓下次失敗可考古）；批次類（意圖判定 15 篇/掃）本來就下輪自癒可不加
- 對應 feedback：deterministic_work_belongs_in_code（重抽合法、修復必確定性）

### L1：quota/limit 類機制，「per-什麼」比「觸發條件」更致命也更容易記丟
現象：推估八月預算時記得 budget gate 存在（runMonitor.ts:53），把每租戶上限當總帳閘，導出「8/31 擋兩輪」錯誤預測；「調 $100」若照錯框架執行，效果（每戶上限翻倍）與 Adam 意圖（總帳封頂）完全不同。
根因：摘要與記憶保存了「有一道閘」，丟失了作用域；作用域藏在 `tenant.monthlyBudgetUsd ?? global` 的 fallback 寫法和註解裡，行號式記憶看不到它。
下次：引用任何 budget/quota/timeout/limit 前先答「per-什麼？」答不出就回機制本體重讀含註解；要動它之前這步不可跳。INFERRED 標籤一路帶著，直到被 VERIFIED 取代。
