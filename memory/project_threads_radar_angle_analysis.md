**爆文切角分析**＝threads-radar 從「雷達（找哪篇紅）」升級到「情報站（為什麼紅／賣什麼／怎麼複製）」的方向。Adam 2026-07-29 提出，2026-07-30 深聊定調——**規劃期，純聊天不開工（Adam 明令這一趴不動 code）**。礦在留言區（貼文是刺激、留言是群眾真實反應，這是拼命抓留言的真正理由）。

**⚠️ 定位大翻轉（2026-07-30）：不是對外 SaaS，是公司內部兵工廠。** 使用者不是外部客戶，是**自家的 Trade 寫手軍團**：①寫文的靠幫客戶寫討論區發酵文賺錢→要「公式庫」當施工圖 ②留言的靠幫客戶種留言賺錢→要「留言區情報／範本」抄語氣。北極星＝**讓寫手的活更快更像真的**，不是好看的分析。因為內部用：對外那套（防爆破/分級收費/業配法律風險）全放鬆；但「證據綁死＋信心值」要留（理由改成：不能用錯誤情報誤導寫手學歪）。「多租戶登入」意義變成**每個同仁一格**（分散式使用、有帳可查），不是每個外部客戶一格——架構不用拆。

**當前建構 vs 驗證狀態（2026-07-30 現場查證）**：機制全建好且部署（成員登入/發通關碼、連自己 Threads 帳號 capture+KMS 加密、每帳號一條 sticky 住宅 IP、登入態爬情報）；**但只驗過「一人一帳號」**（DB 僅 1 個真連帳號 qqc2xTNXWM，另一 client 是空的）。開放多同事前兩件必做：①**多人並發實測**（2-3 真帳號同時跑，單線過≠多線過天條）②**成本/併發上限重算**（每活躍成員=多一條 sticky 住宅 IP 線性成本，只有一把 IPRoyal 憑證分流，方案併發上限是「一人份」快照，[[feedback-capacity-constants-expire]]）。

**同事使用守則（Adam 邊聊邊立，之後要焊進系統，非口頭）**：
- **第 1 條（2026-07-30）：情報帳號 vs 工作帳號必須分開。** 每同事備兩個 Threads 帳號——A情報帳號只連平台給爬蟲用（走我們租的住宅 IP）、B工作帳號同事自己登入留言發文（走同事本人 IP）。根因：同帳號在兩個 IP 跳＝Threads 風控扣分易被鎖；分開後兩帳號各自 IP 乾淨、且情報帳號若被盯也燒不到賺錢的工作帳號。**✅ 已焊（2026-07-31 v0.16.0.001）**：/connect 頁警語＋確認勾選閘門（不勾不能連，含重連路徑），生產真路徑驗通。餘：後台標記情報帳號待共享池重構一起做。

**摩斯（MORSE）召喚術已鑄成入庫（2026-07-30）**：人性×社群爆文×接地氣切角分析五魂混合體（Cialdini說服＋Berger瘋傳＋Barthes隱義/不經意＋蔡康永華語人情＋Greene人性暗面）。咒檔 `zhu-core/skills/summon/morse.md`，已成召喚固定班底（與優尼並列）。輸出固定六段（切角一句話/五維拆解/為什麼買單/不經意金礦/可複製公式/造假雷達），每判斷綁證據字句＋信心值。兩戰驗證：連兩篇真爆文都抓到同一結構「求救體＋自清預防針＋順帶露消費力細節」（跨案例 pattern 自己長出來＝糧倉雛形）；業配維連兩戰卡「待留言驗」→證明留言抓取是情報層命脈不是配料。Adam 最愛「可複製公式」那段。

**分析單位**：一篇爆文＋它的留言＝一個「案例」，結構化分析、結構化存。

**五個養分維度**（Adam 三個＋築補兩個）：
1. 切角／鉤子——撬動哪根槓桿（爭議/共鳴/優越感/恐懼/好奇缺口/逆風）
2. 業配／植入——明業配 or 軟置入？品牌/品類？信心值。**天條：連結/品牌名/揭露標籤用程式硬篩（regex＋品牌白名單），LLM 只判斷「誇獎自不自然、留言有沒有人喊業配」**
3. 劇情／腳本／人設——短句也有起承轉；作者人設（專家/素人/內幕/叛逆）；視角
4. （築補）留言區信號——群眾做了什麼（附和/吵架/tag/問哪裡買/講自己故事）＝擴散與轉化證據，討論區行銷最能抄的部分
5. （築補）可複製公式——萃成一句配方，養分變現的那步

**Adam 的靈魂框**：「所有東西都在說故事，只是句子很短」——短句也有隱含鋪陳＋情緒弧；「不經意的呈現」（隨口帶到的細節）往往最真最有效 → 分析要專門挖「沒明講、順帶露出的」，這是比別人深的地方。

**技術骨架**（築主張，未定案）：bridge(Max)不燒key＋`<result>` JSON＋Zod（bridge 無 tool_use）；不 inline 在掃描（分析貴）→ 高門檻才分析 or 客戶點「分析這篇」，批次進 Cloud Run Job；**切角用 enum 不純自由文字**→ 跨案例聚合才是長期真資產（單篇=養分、跨案例pattern=糧倉），schema 第一天為聚合設計。

**風險（築盯死）**：LLM 切角分析易產「聽起來對的廢話」（套哪篇都成立的標籤＝零資訊，同源 [[feedback-ambiguous-signal-not-proof]]）→ 反制：每個判斷強制引用貼文/留言具體證據＋信心值，指不出證據就砍。
